DD2 세이브 매니저
=================

드래곤즈 도그마 2(Steam, Windows)의 세이브를 백업하고 수정하는 프로그램이에요.
팬이 만든 비공식 도구이며, 캡콤과는 관련이 없어요.

지원 언어: English, 한국어, 日本語, 简体中文, Español, Français
(언어 메뉴는 창 오른쪽 위에 있어요.)


실행 방법

  1. 폴더 전체를 원하는 곳에 압축 해제하세요.
  2. DD2SaveManager.exe를 실행하세요.

따로 설치할 것은 없어요. 처음 실행하면 설치된 게임 파일에서 아이템 이름, 아이콘,
스킬 목록을 읽어 와요(몇 초 걸려요). 게임이 업데이트된 뒤에는 편집 > 아이템의
"게임 파일 다시 읽기"를 눌러 주세요.

필요 환경: Windows 10 또는 11(64비트). 창은 Microsoft Edge WebView2 런타임을 써요
(Windows 11에는 기본 포함). 없으면 Edge나 Chrome 창으로 대신 열려요.


할 수 있는 것

  백업
    - 세이브 폴더의 파일 전체를 메모와 함께 복사해 둬요.
    - 백업으로 되돌려요. 되돌리기 전 세이브는 먼저 자동 백업돼요.

  편집 (세이브를 고르고, 값을 바꾼 뒤 "세이브에 적용")
    - 골드와 림. 게임 모드(캐주얼/노멀/하드)는 보여 주기만 하고 바꾸지 않아요.
      모드는 게임 타이틀 화면의 Options에서 바꿔 주세요.
    - 빠른 이동: 본편 지도의 고정 귀로의 초석을 찾은 것으로 표시.
    - 각성자와 메인 폰: 이름, 현재 직업, 레벨, 경험치, 직업 포인트, 성장치,
      직업 해금과 누적 경험치.
    - 스킬과 어빌리티: 커스텀 스킬(강화형 포함), 일반 스킬, 어빌리티를 직업별로
      또는 한꺼번에 해금.
    - 메인 폰: 성격, 목소리 높낮이, 특수 기술, 호감도. 메인 폰과 파티에 있는
      서포트 폰의 용내림 되돌리기.
    - 아이템: 수량, 강화 횟수, 추가와 빼기.
    - 외형: 캐릭터의 외형을 프리셋으로 저장해 각성자나 메인 폰에게 입히기.
      다른 유저에게서 고용한 서포트 폰의 외형도 가져올 수 있어요. "외형 수치표"는
      그 외형을 게임의 캐릭터 편집 화면에 입력할 숫자로 보여 줘요.


안전

  - 적용과 복원은 게임을 끈 뒤에 하세요. 게임이 켜져 있으면 프로그램이 막아요.
    보기와 백업은 언제든 돼요.
  - 적용하거나 복원할 때마다 직전 세이브를 먼저 자동으로 백업해요.
  - 세이브는 만든 Steam 계정에 묶여 있어서, 다른 계정의 세이브는 열 수 없어요.
  - 바이트 단위로 똑같이 다시 만들 수 있는 세이브만 수정하고, 아니면 읽기 전용으로 열어요.
  - Steam 클라우드에도 세이브 사본이 있어요. 수정이나 복원 뒤에 Steam이 어느 쪽을
    쓸지 물으면 로컬 파일을 고르세요.

  사용에 따른 책임은 사용자에게 있어요. 프로그램은 새로 쓴 세이브를 다시 읽어 확인한
  뒤에야 기존 세이브를 바꾸지만, 모든 종류의 수정을 게임에서 확인한 것은 아니에요.
  일부 값은 세이브 데이터를 보고 추정한 것이라 프로그램 안에 그렇게 적혀 있어요.
  새로운 종류의 수정은 먼저 하나만 해 보고, 백업은 남겨 두세요.

  가 본 적 없는 초석으로 건너뛰거나 일찍 해금하면 이야기 일부를 건너뛸 수 있어요.
  폰 정보는 다른 유저와 온라인으로 공유되니 배려해 주세요.


저장 위치

  백업, 외형 프리셋, 게임에서 읽어 온 자료는 이 폴더 안(backups\, looks\, data\)에
  저장돼요. 이 폴더에 쓸 수 없으면 %LOCALAPPDATA%\DD2SaveManager 아래에 저장돼요.
  프로그램 폴더를 지우면 그 안의 백업도 지워져요. 프로그램이 백업을 직접 지우는
  일은 없고, "휴지통으로"는 _trash 폴더로 옮기기만 해요.

  프로그램은 전부 이 PC 안에서만 돌아요. 자기 창을 위해 127.0.0.1에 작은 로컬 서버를
  띄울 뿐, 인터넷으로 보내는 것은 없어요.


제작 참고와 라이선스

  각각 무엇인지와 exe를 다시 빌드하는 방법은 BUILD.txt에 적혀 있어요.

  않고, 이름과 아이콘은 사용자의 게임 파일에서 읽어 와요.
