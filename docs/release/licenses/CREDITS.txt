DD2 Save Manager - credits

This tool's own code was written from scratch. It builds on what others worked out and
published about the game's formats:

  MandarinJuice (mi5hmash, MIT)        https://github.com/mi5hmash/MandarinJuice
      The save file container and its encryption.

  ree-save-editor (kvasszn)            https://github.com/kvasszn/ree-save-editor
      The save tree format. The files in data\dd2\ list how the game's data tables that
      this tool reads are laid out, and what the enum values in them are called; they
      were taken from that project's type and enum dumps for Dragon's Dogma 2.

  REE.PAK.Tool (Ekey)                  https://github.com/Ekey/REE.PAK.Tool
      The game's archive format.

  REMSG_Converter (dtlnor)             https://github.com/dtlnor/REMSG_Converter
      The game's message file format.
